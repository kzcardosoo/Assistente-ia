# Assistente-ia

- **`aiko-assistente/`**: o projeto da assistente virtual anime para desktop (Electron + VRM + Python). Veja o [README do projeto](aiko-assistente/README.md) para instalar e usar.
- **`Guia_Assistente_Virtual_Anime.pdf`**: guia em PDF explicando, passo a passo, como a assistente é construída.
- **`gerar_pdf.py`**: script que gera o PDF.
